# NPC DSC 2026 - preprocessing pipeline

Open the notebooks from this folder, in order:

1. `01_EDA.ipynb`: exploratory analysis of the raw 48 kHz audio (runs `scripts/00_eda_features.py`)
2. `02_preprocessing.ipynb`: runs the preprocessing scripts below in order and shows their outputs
3. `03_birdnet_baseline.ipynb`: BirdNET embeddings + simple classifiers, Unknown rejection, first submission (runs `scripts/06_birdnet_embeddings.py`)

```
pip install -r requirements.txt
```

| Script | Output |
|---|---|
| `scripts/00_eda_features.py` | `outputs/eda/clip_stats.csv`, `spectra.npz`, `mel_summary.npy` |
| `scripts/01_inventory.py` | `outputs/inventory_*.csv`, `group_summary.csv`, `channel_check.csv` |
| `scripts/02_cache_audio.py` | `cache/audio/{train,test}/*.npy` (mono 32 kHz), `outputs/audio_stats.csv` |
| `scripts/03_make_folds.py` | `outputs/folds.csv` (group-held-out folds) |
| `scripts/04_activity_and_noise.py` | `cache/activity/*.npy`, `cache/noise/*.npy`, `outputs/activity_summary.csv`, `noise_bank.csv` |
| `scripts/05_compare_frontends.py` | `outputs/frontend_comparison.csv`, `outputs/oof_*.csv` |
| `scripts/06_birdnet_embeddings.py` | `outputs/03_birdnet/birdnet_windows.npz` (BirdNET v2.4, 1024-d per 3 s window) |
| `scripts/06b_perch_embeddings.py` | `outputs/03_birdnet/perch_windows.npz` (Perch v2 via perch-hoplite, 1536-d per 5 s window; run in `.venv313` from Terminal, resumes if interrupted) |
| `scripts/06c_perch_species.py` | `outputs/03_birdnet/perch_species_clip.npz`: Perch v2 species scores per clip (max over windows), referee/features only; run in `.venv313`, resumable |
| `scripts/07_anchor_check.py` | `outputs/03_birdnet/anchor_check.csv`: offline ranking of every `submission_*.csv` against BirdNET anchor labels (use when out of submissions) |
| `scripts/08_open_set_v2.py` | `outputs/03_birdnet/submission_v2_r*.csv`: improved Unknown rule + self-trained classifier (`--emb birdnet/perch/both`) |
| `scripts/09_cendrawasih_trim.py` | `outputs/03_birdnet/submission_v3_cend45_veto.csv`: keeps only the 45 most Cendrawasih-like test clips and vetoes parrot/shama-like ones (hypothesis test) |
| `scripts/10_kutilang_veto.py` | `outputs/03_birdnet/submission_v4_kutveto.csv`: Kutilang -> Unknown when Perch's top-3 holds a species never in training Kutilang's top-3 (cost ~1.6% of real Kutilang) |
| `scripts/11_train_cnn.py` | `outputs/04_cnn/<run>/fold<k>.npz`, `full.npz`: EfficientNet-B0 fine-tuned on PCEN spectrograms (GPU PC; `requirements_cnn.txt`). Probabilities + embeddings for all clips |

- All settings: `src/config.py`
- Front-ends (log-mel, PCEN, normalisation): `src/features.py`
- Augmentation: `src/augment.py`
- Training data loader (`BirdWindowDataset`, which also works as a torch Dataset): `src/dataset.py`
- The notebooks are generated by `tools/build_eda_notebook.py`, `tools/build_notebook.py` and `tools/build_birdnet_notebook.py`. To change their text, edit those files and re-run them.

The data is read from `../DSC_Dataset` (or `../kaggle` if that is where it is). To use another location, set the `NPC_DATA` environment variable.
