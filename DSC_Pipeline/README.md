# NPC DSC 2026 - preprocessing pipeline

Open the notebooks from this folder, in order:

1. `01_EDA.ipynb`: exploratory analysis of the raw 48 kHz audio (runs `scripts/00_eda_features.py`)
2. `02_preprocessing.ipynb`: runs the preprocessing scripts below in order and shows their outputs

```
pip install -r requirements.txt
```

| Script | Output |
|---|---|
| `scripts/00_eda_features.py` | `outputs/eda/clip_stats.csv`, `spectra.npz`, `mel_summary.npy` |
| `scripts/01_inventory.py` | `outputs/inventory_*.csv`, `group_summary.csv`, `channel_check.csv` |
| `scripts/02_cache_audio.py` | `cache/audio/{train,test}/*.npy` (mono 32 kHz), `outputs/audio_stats.csv` |
| `scripts/03_make_folds.py` | `outputs/folds.csv` (group-held-out folds) |
| `scripts/04_activity_and_noise.py` | `cache/activity/*.npy`, `cache/noise/*.npy`, `outputs/activity_summary.csv`, `noise_bank.csv` |
| `scripts/05_compare_frontends.py` | `outputs/frontend_comparison.csv`, `outputs/oof_*.csv` |

- All settings: `src/config.py`
- Front-ends (log-mel, PCEN, normalisation): `src/features.py`
- Augmentation: `src/augment.py`
- Training data loader (`BirdWindowDataset`, which also works as a torch Dataset): `src/dataset.py`
- The notebooks are generated by `tools/build_eda_notebook.py` and `tools/build_notebook.py`. To change their text, edit those files and re-run them.

The data is read from `../DSC_Dataset` (or `../kaggle` if that is where it is). To use another location, set the `NPC_DATA` environment variable.
